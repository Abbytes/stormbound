# Stormbound (Pocket)

Mobile-first web TCG inspired by Pokémon TCG Pocket.

**Live:** https://abbytes.github.io/stormbound/

## Play the first match
1. Open **Play** (Dawnpack vs Pack AI).
2. Select a **Basic** from your hand → tap the glowing **Active Spot**.
3. Optionally Bench more Basics → **Start Battle**.
4. Tap **⚡** → tap Active/Bench to attach 1 Energy.
5. Use an attack on the enemy Active when you have enough ⚡.
6. Evolve Stage cards onto matching lines. First to **3 points** wins (Apex KO = 2).

## Dev
```bash
npm install
npm run dev
npm run build   # base: /stormbound/
```

## Stack
React + Vite + TypeScript + Tailwind.
